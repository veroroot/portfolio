## 다이어그램 추가

프로젝트 `id` 폴더에 이미지만 넣으면 경로를 따로 적지 않아도 됩니다.

```text
assets/projects/mlops/architecture.png
assets/projects/isoda/architecture.png
assets/projects/smartclm/architecture.png   # 또는 기존 smartclm_architecture.png
assets/projects/saegim/architecture.png
```

권장 파일명: `architecture.png` (`.jpg` / `.webp` / `.svg` 도 가능)
